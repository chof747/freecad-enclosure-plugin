# Release Notes: 001 Bootstrap Enclosure Workbench

## Included

- Initial FreeCAD workbench scaffold and toolbar command registration.
- Parametric enclosure create/update command contract.
- Install/update/smoke helper scripts and debug workflow docs.

## Limitations

- No KiCad import integration in this release.
- Screw-hole and connector cutout automation are planned, not implemented.
- Geometry generation currently targets deterministic defaults only.
